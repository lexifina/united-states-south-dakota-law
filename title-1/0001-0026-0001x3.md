# SDCL 1-26-1.3. Delegation of duties by code counsel.
The code counsel, with the consent of the director of the Legislative Research Council, may delegate the duties imposed by this chapter to other persons in the council's office. Each person to whom the duties are delegated has the same power and authority as the code counsel for the purposes of this chapter. The papers specifying the delegation of duties must be filed with the secretary of state.
